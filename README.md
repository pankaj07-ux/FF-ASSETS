# 🔥 FF-ASSETS

Premium Free Fire assets repository for Discord bots, profile cards, outfit inspectors, banners, avatars and cosmetic systems.

## ✨ Features

* ✅ Free Fire Avatars
* ✅ Banners
* ✅ Character Renders
* ✅ Item Icons
* ✅ ID-based asset system
* ✅ Easy Discord bot integration
* ✅ Raw GitHub CDN support
