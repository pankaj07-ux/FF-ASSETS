# ff-assets

Organized Free Fire asset folder ready for GitHub upload.

Folder structure:
- avatars/{ID}.png       -> use with basicInfo.headPic
- banners/{ID}.png       -> use with basicInfo.bannerId
- characters/{ID}.png    -> use with profileInfo.avatarId
- icons/{ID}.png         -> general item/icon fallback

Raw GitHub URL format after uploading this repo:
https://raw.githubusercontent.com/YOUR_USERNAME/ff-assets/main/avatars/{ID}.png
https://raw.githubusercontent.com/YOUR_USERNAME/ff-assets/main/banners/{ID}.png
https://raw.githubusercontent.com/YOUR_USERNAME/ff-assets/main/characters/{ID}.png
https://raw.githubusercontent.com/YOUR_USERNAME/ff-assets/main/icons/{ID}.png

Keep filenames exactly as numeric IDs.
